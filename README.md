# 🌱 AgriPulse — Adaptive Irrigation & Water Intelligence Dashboard

> **Smarter Water. Healthier Crops.**

AgriPulse is an **IoT-based smart irrigation and water intelligence system** designed to monitor agricultural field conditions and support adaptive irrigation decisions.

The project combines **IoT, smart agriculture, adaptive irrigation, and interactive data visualization** to help monitor soil conditions, water usage, weather parameters, and irrigation performance through a modern web dashboard.

---

## 🚀 Features

* 🌱 Real-time soil moisture monitoring
* 🌡️ Temperature and humidity monitoring
* 💧 Water tank level monitoring
* 🚿 Water flow monitoring
* 🌧️ Rainfall probability tracking
* ⚙️ Adaptive irrigation status
* 📊 Interactive charts and analytics
* 💦 Water consumption monitoring
* 🌍 Field/zone monitoring
* 🔔 Alerts and notifications
* 🔌 IoT system health monitoring
* 📈 Historical sensor trends
* 💡 Water-saving insights
* 📱 Fully responsive dashboard
* 🎛️ Interactive irrigation control prototype
